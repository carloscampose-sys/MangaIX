# Crear Placeholders Rápidos (Opcional)

Si quieres ver el componente funcionando mientras extraes las imágenes reales, puedes crear placeholders temporales.

## Opción 1: Usar Emojis como Placeholder (Más Rápido)

1. Ve a https://www.photopea.com/
2. File > New (200x200px, fondo transparente)
3. Agrega un emoji grande en el centro:
   - Masculino: 👨 o 🎮
   - Femenino: 👩 o 🌸
   - Otro: 🌈 o 🎨
4. File > Export As > PNG
5. Guarda como `gender-masculino.png`, `gender-femenino.png`, `gender-otro.png`

## Opción 2: Usar Figuras Simples

1. Ve a https://www.photopea.com/
2. File > New (300x300px, fondo transparente)
3. Dibuja una figura simple con las herramientas:
   - Círculo para la cabeza
   - Rectángulo redondeado para el cuerpo
   - Colores: verde para masculino, rosa para femenino, morado para otro
4. File > Export As > PNG
5. Guarda con los nombres correspondientes

## Opción 3: Descargar Iconos Gratuitos

1. Ve a https://www.flaticon.com/
2. Busca "avatar" o "person"
3. Descarga 3 iconos diferentes (PNG con transparencia)
4. Renombra a los nombres correctos

## Nombres de Archivos Requeridos

- `public/gender-masculino.png`
- `public/gender-femenino.png`
- `public/gender-otro.png`

## Nota Importante

Estos son solo placeholders temporales. Las imágenes finales deben ser las figuras extraídas de la imagen de referencia según las instrucciones en `design-references/INSTRUCCIONES_EXTRACCION_FIGURAS.md`.
