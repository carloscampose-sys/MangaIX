## Proceso de Extracción

Ver instrucciones detalladas en: `design-references/INSTRUCCIONES_EXTRACCION_FIGURAS.md`

### Opción Rápida (5 minutos)

1. Ve a https://www.remove.bg/
2. Sube la imagen de referencia
3. Descarga sin fondo
4. Abre en Photopea (https://www.photopea.com/)
5. Recorta cada personaje individualmente
6. Remueve el texto con Clone Stamp
7. Guarda como PNG en esta carpeta (`public/`)

### Herramientas Recomendadas

- **remove.bg** - Remover fondo automáticamente
- **Photopea** - Editor online gratuito (alternativa a Photoshop)
- **TinyPNG** - Optimizar peso de archivos
