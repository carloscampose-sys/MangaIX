Carga Inicial\n```\nApp monta\n    ↓\nuseEffect se ejecuta\n    ↓\nloadSourceOrder() desde localStorage\n    ↓\nsetSourceOrder(savedOrder)\n    ↓\nComponente se re-renderiza\n    ↓\nBotones se renderizan en orden guardado\n    ↓\nuseSwapy hook se inicializa\n    ↓\nSwapy está listo para drag\n```\n\n### 2. Usuario Arrastra\n```\nUsuario hace clic en botón\n    ↓\nCursor cambia a \"grabbing\"\n    ↓\nUsuario arrastra el botón\n    ↓\nSwapy detecta movimiento\n    ↓\nBotón obtiene clase \"swapping\"\n    ↓\nFeedback visual aparece (opacidad, escala, brillo)\n    ↓\nOtros botones se desplazan\n```\n\n### 3. Usuario Suelta\n```\nUsuario suelta el botón\n    ↓\nSwapy dispara evento \"swapEnd\"\n    ↓\nuseSwapy hook captura el evento\n    ↓\nExtrae nuevo orden del DOM\n    ↓\nLlama handleSourceOrderChange(newOrder)\n    ↓\nsaveSourceOrder(newOrder)\n    ↓\nsetSourceOrder(newOrder)\n    ↓\nshowToast(\"✨ Orden actualizado\")\n    ↓\nComponente se re-renderiza\n    ↓\nBotones se renderizan en nuevo orden\n    ↓\nFeedback visual desaparece\n    ↓\nAnimación \"swapPulse\" se ejecuta\n```\n\n### 4. Persistencia\n```\nNuevo orden guardado en localStorage\n    ↓\nUsuario recarga página\n    ↓\nApp monta\n    ↓\nuseEffect se ejecuta\n    ↓\nloadSourceOrder() desde localStorage\n    ↓\nRetorna orden guardado\n    ↓\nsetSourceOrder(savedOrder)\n    ↓\nBotones se renderizan en orden guardado\n    ↓\nUsuario ve el mismo orden que dejó\n```\n\n## Estilos CSS\n\n### Estados del [\"tumanga\", \"manhwaweb\", \"ikigai\"]        (orden por defecto)\n- [\"ikigai\", \"tumanga\", \"manhwaweb\"]        (reordenado)\n- [\"manhwaweb\", \"ikigai\", \"tumanga\"]        (reordenado)\n\nTamaño: ~50 bytes\nTipo: String (JSON)\n```\n\n### Operaciones\n```\n┌─────────────────────────────────────────────────────────────┐\n│ Guardar Orden                                               │\n├─────────────────────────────────────────────────────────────┤\n│ localStorage.setItem(\"sourceOrder\",                         │\n│   JSON.stringify([\"ikigai\", \"tumanga\", \"manhwaweb\"])       │\n│ )                                                           │\n└─────────────────────────────────────────────────────────────┘\n\n┌─────────────────────────────────────────────────────────────┐\n│ Cargar Orden                                                │\n├─────────────────────────────────────────────────────────────┤\n│ const saved = localStorage.getItem(\"sourceOrder\")           │\n│ const order = JSON.parse(saved)                             │\n│ // [\"ikigai\", \"tumanga\", \"manhwaweb\"]                      │\n└─────────────────────────────────────────────────────────────┘\n\n┌─────────────────────────────────────────────────────────────┐\n│ Limpiar Orden                                               │\n├─────────────────────────────────────────────────────────────┤\n│ localStorage.removeItem(\"sourceOrder\")                      │\n│ // Vuelve al orden por defecto en próxima carga             │\n└─────────────────────────────────────────────────────────────┘\n```\n\n## Animaciones\n\n### swapPulse\n```\nTiempo: 0.3 segundos\nCurva: ease\n\n0%    ┌─────────────────────────────────────────┐\n      │ scale(1)                                │\n      │ ▢ Botón en tamaño normal                │\n      └─────────────────────────────────────────┘\n\n50%   ┌─────────────────────────────────────────┐\n      │ scale(1.08)                             │\n      │ ▢▢ Botón crece un poco                  │\n Pasar mouse\n   └─ Cursor cambia a \"grab\" 🖐️\n\n2. Hacer clic\n   └─ Cursor cambia a \"grabbing\" ✊\n\n3. Arrastrar\n   └─ Botón se mueve suavemente\n   └─ Feedback visual aparece\n\n4. Soltar\n   └─ Botón se coloca en nueva posición\n   └─ Animación swapPulse se ejecuta\n   └─ Toast aparece\n```\n\n### Mobile/Touch\n```\n1. Tocar botón\n   └─ Feedback táctil (haptic si disponible)\n\n2. Arrastrar\n   └─ Botón se mueve suavemente\n   └─ Feedback visual aparece\n\n3. Soltar\n   └─ Botón se coloca en nueva posición\n   └─ Animación swapPulse se ejecuta\n   └─ Toast aparece\n```\n\n## Casos de Uso\n\n### Caso 1: Usuario Prefiere ManhwaWeb\n```\nAntes:  [TuManga] [ManhwaWeb] [Ikigai]\n        Arrastra ManhwaWeb al inicio\nDespués: [ManhwaWeb] [TuManga] [Ikigai]\n        ✨ Orden de fuentes actualizado\n        Al recargar: [ManhwaWeb] [TuManga] [Ikigai]\n```\n\n### Caso 2: Usuario Prefiere Ikigai\n```\nAntes:  [TuManga] [ManhwaWeb] [Ikigai]\n        Arrastra Ikigai al inicio\nDespués: [Ikigai] [TuManga] [ManhwaWeb]\n        ✨ Orden de fuentes actualizado\n        Al recargar: [Ikigai] [TuManga] [ManhwaWeb]\n```\n\n### Caso 3: Usuario Limpia localStorage\n```\nAntes:  [Ikigai] [TuManga] [ManhwaWeb] (guardado)\n        Limpia localStorage\nDespués: [TuManga] [ManhwaWeb] [Ikigai] (por defecto)\n```\n\n## Conclusión\n\nLa funcionalidad de draggable source buttons proporciona una experiencia de usuario intuitiva y personalizable, permitiendo a los usuarios organizar los botones de fuentes según sus preferencias.\n\n---\n\n**Última actualización:** 2025-12-28\n
